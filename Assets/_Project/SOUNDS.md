# Звуки Rocket Wars

Все звуки игры — обычные файлы в папке **`Assets/_Project/Resources/Sounds/`**. Синтеза в коде нет.

## Как заменить звук

1. Сделайте свой файл (**wav**, **ogg** или **mp3**).
2. Назовите его **точно как в таблице** (регистр важен, расширение — любое).
3. Положите в `Resources/Sounds/` вместо старого.
   - Если формат тот же (`Explosion.wav` → новый `Explosion.wav`) — просто замените файл в проводнике, настройки импорта сохранятся.
   - Если другой (`Explosion.wav` → `Explosion.ogg`) — удалите старый файл, иначе Unity не поймёт, какой из двух брать.
4. Вернитесь в Unity — файл переимпортируется сам. Перекомпилировать ничего не нужно.

Нет файла — звук просто не играет, в консоли будет предупреждение `Нет звука Resources/Sounds/...`.

Часть звуков — ещё **заглушки** (прежние процедурные, 22 кГц, моно); настоящие уже у шагов, прыжка, ракеты, пульта и фона в игре. Заменять можно по одному.

## Настройки импорта (ставятся сами)

При первом импорте нового файла в эту папку `Editor/SoundImportSettings.cs` выставляет:

| Что | Load Type | Формат | Моно |
|---|---|---|---|
| эффекты | Decompress On Load | PCM | да |
| `Ambient*` | Streaming | Vorbis 70 % | нет (стерео можно) |

Потом их можно менять в инспекторе — повторно скрипт их не трогает.

## Общие советы

- **Тишина в начале** — обрежьте: звук должен начинаться сразу (особенно выстрелы, шаги, клики).
- **Громкость** — нормализуйте пик примерно до −1 dBFS; итоговый микс задаётся громкостью в коде (столбец «Громк.»).
- **3D-звуки** лучше делать моно — Unity всё равно сведёт их в точку в пространстве.
- **Лупы** (🔁) должны стыковаться без щелчка: конец плавно переходит в начало, без тишины по краям.
- Длина — ориентир: под неё подстроены анимации и интервалы. Сирена звучит ровно 2,5 с перед пуском.

## Где менять громкость и дальность

- Эффекты — в месте вызова: поиск по проекту `Sfx.Siren`, `Sfx.Gunshot` и т. д. (аргументы `volume` и `maxDistance`).
- Фон — константы `MenuVolume` и `MatchVolume` в `Scripts/Core/Ambience.cs`.
- Добавить новый звук: положите файл и добавьте строку в `Scripts/Core/Sfx.cs` по образцу
  `public static AudioClip Имя => Get(nameof(Имя));`
