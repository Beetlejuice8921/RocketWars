# Rocket Wars — план разработки (Unity 6)

Мультиплеерная командная 3D шутер-аркада для ПК, Internet / LAN.

## Утверждённые правила игры

| Параметр | Значение |
|---|---|
| Команды | 2, у каждой свой парящий воксельный остров ~105×68 м |
| Террейн | кубики 1 м: нижний слой — камень (HP 200), над ним 1–4 кубика земли с травой (HP 50) |
| Игрок | рост 2 м, 100 HP, бег / прыжок / присед, автоподъём на 1 кубик |
| Присед | урон × 2/3 |
| Падение с острова | через 3 с появление сверху своего острова, **−50 HP**; если HP ≤ 50 → Downed |
| 0 HP | игрок не умирает, а **лежит (Downed)** с иконкой SOS |
| Лежащий игрок | **неуязвим**, не двигается, не пользуется пультами |
| Подъём | союзник удерживает `E` 3 с рядом (прерывается уроном/отпусканием), встаёт с 50 HP |
| Лежащий упал (разрушились кубики) | появляется сверху своего острова и продолжает лежать |
| Шахты | 6 на команду, случайная расстановка, HP 150, перезарядка 60 с |
| Наведение | пульт: X (старт/стоп горизонтальной линии), Y (старт/стоп вертикальной), Launch |
| Карта на пульте | вся карта: оба острова (свой выделен), видны только свои шахты; стрелять можно и по своему |
| Урон взрыва | ≤5 м: 500, 5–8 м: 100, 8–14 м: 25 — по всем игрокам, кубикам, шахтам без учёта команд |
| Ракета в пустоту | улетает вниз, без урона |
| Поражение в раунде | все игроки команды одновременно лежат |
| Матч | до 4 побед (максимум 7 раундов), каждый раунд — новые острова |
| Другое оружие | не реализуем (архитектура урона расширяемая) |

## Технический стек

- Unity 6 (6000.x LTS), URP, Input System, UI Toolkit (меню/таблица), world-space Canvas (экран пульта).
- Netcode for GameObjects + Unity Transport, host-authoritative.
- Internet: Unity Multiplayer Services — Sessions (Lobby + Relay).
- LAN: прямое подключение + UDP-broadcast discovery.
- Террейн: собственный воксельный меш по чанкам 16×16, генерация по seed.

## Этапы

### 1. Прототип ядра (офлайн) — ~2,5 недели
- `IslandGenerator`: Perlin-высоты 1–4 + маска рваного края, seed.
- `VoxelIsland` / `Chunk` / `MeshBuilder`: меш только видимых граней, MeshCollider на чанк, HP кубиков, перестройка при разрушении.
- `FpsController`: бег, прыжок, присед, step-up 1 м.
- `PlayerHealth`: состояния Alive/Downed, модификатор приседа, неуязвимость лежащего.
- `FallRespawn`: детект падения, задержка 3 с, −50 HP, сохранение состояния Downed.
- `ReviveInteraction`: удержание `E` 3 с, иконка SOS (видна сквозь стены).
- Расстановка 6 шахт на остров (ровная площадка, минимальная дистанция).

### 2. Пульт и ракета — ~1,5 недели
- `AimConsole`: машина состояний `Idle → X движется → X стоп → Y движется → Y стоп → Launch`, ping-pong линии.
- Экран: вид сверху на всю карту, свой остров другим цветом, отметки только своих шахт (вражеские не показываются), предупреждение при цели на своём острове.
- Пересчёт точки экрана в мир, raycast вниз; промах → ракета падает в пустоту без урона.
- `Rocket`: детерминированная парабола (старт, цель, время запуска).
- `Explosion`: каскадный урон через `IDamageable` + `DamageInfo` (источник, позиция).
- Сирена (звук + вращающийся свет), перезарядка 60 с, статусы READY / IN PROGRESS.

### 3. Сеть — ~3 недели
- NetworkManager, Host/Client, автобаланс команд.
- Игроки: клиентское движение с серверной проверкой; HP/состояние — NetworkVariable.
- Террейн: seed + рассылка `BlockDamaged`, догрузка изменений для подключившихся.
- Пульт: ServerRpc на кнопки, блокировка пульта за одним игроком.
- Ракеты, урон, подъём, статистика — только на сервере.
- Sessions (Lobby + Relay), LAN discovery, обработка отключений (выход хоста → конец матча).

### 4. Игровой цикл — ~1 неделя
- `MatchManager`: `Ожидание → Отсчёт 3..2..1 → Раунд → Конец раунда → … → Таблица`.
- Проверка поражения: все игроки команды Downed.
- До 4 побед (максимум 7 раундов); новый seed, полное HP, перезаряженные шахты каждый раунд.
- HUD счёта раундов «1 | ROUND 2 | 2».

### 5. UI — ~1,5 недели
- Главное меню (одно окно): создать комнату, поиск комнаты (Internet + LAN), выход, громкость (AudioMixer + PlayerPrefs).
- HUD: HP, состояние, прогресс подъёма, перезарядка шахты.
- Таблица результатов: 2 колонки по командам; положил врагов / лёг сам / поднял / шахты / падения / положил своих.
- Достижения (ScriptableObject) с подсказкой при наведении: Снайпер, Медик, Сапёр, Лемминг, Дружеский огонь, Несгибаемый.

### 6. Контент и полировка — ~2 недели
- Модели: шахта, пульт, ракета, воксельный персонаж.
- Звуки: сирена, запуск, полёт, взрыв, шаги, урон, падение, подъём.
- VFX: дымный след, воксельный гриб, обломки кубиков.
- Оптимизация: лимит перестроек чанков за кадр, пулинг, профилирование сети.

### 7. Тестирование и сборка — ~1 неделя
- Multiplayer Play Mode, Network Simulator (задержка/потери), тесты LAN и Relay.
- Сборка Windows x64.

**Итого: ~13–15 недель** на одного разработчика до играбельной версии.
