# Rocket Wars — материалы для VK Игр

Всё для раздела dev.vk.com → Приложения → игра. Графику пересобирает `python make_vk_assets.py`
(берёт иконку, обложку и скриншоты из `../Marketing` — материалов Яндекса).
Требования сверены с документацией VK для разработчиков 14.10.2026.

## Оформление (Общие настройки → Оформление)
| Поле VK | Требование VK | Файл |
|---|---|---|
| Универсальная иконка | 576×576, JPG/PNG | `icon_576.png` |
| Иконка для каталога и сниппетов | 278×278 (иначе делается из универсальной) | `icon_278.png` |
| Маленькая иконка | 150×150 (иначе делается из универсальной) | `icon_150.png` |
| Фавикон | 32×32, PNG/JPG/GIF, ≤ 50 КБ, загружается **вручную** | `favicon_32.png` (он же уже лежит в сборке как `favicon.png`) |
| Большой сниппет | 1120×630, без важного внизу (VK пишет поверх свой текст) | `snippet_1120x630.png` |
| Скриншоты | одинаковые по размеру и ориентации; VK указывает 600×1200 | `screenshots/*.jpg` — горизонтальные 1200×600 |
| Видео | показывается на экране запуска и в карусели каталога | `../Trailer/RocketWars_trailer.mp4` (28 с, 1080p) |
| Экран запуска | иконка в формате Lottie — по желанию | — |

Скриншоты: ориентацию выбирают **до** загрузки — при её смене VK удаляет уже загруженные. Выбирать горизонтальную.
Если VK не примет 1200×600, нужна другая нарезка — поменять размер в `make_vk_assets.py`.

## Тексты (Информация)
См. `TEXTS.md`: название, слоган, краткое и полное описание, описание сценариев для модерации.

## Отображение (Настройки → Отображение)
- Широкоформатный режим — **включить** (игре нужен большой экран; до прохождения модерации его видят только админы).
- Размер iframe: максимальный, 1000×(по высоте экрана, напр. 750); минимум VK — 630×600.
- Мобильные платформы в заявке **не выбирать**: управления с телефона нет.

## Чек-лист модерации VK (каталог)
- [x] Отключение звука — «Опции → Громкость» до 0; звук глушится, когда вкладка скрыта / приложение VK свёрнуто / идёт реклама.
- [ ] **Связь с поддержкой** — нужна ссылка (сообщество VK, почта или страница). Вписать в `WebPlatform.VkSupportUrl`
      (Scripts/Core/Platform/WebPlatform.cs) — в меню появится кнопка «Поддержка». Пока пусто — сборка VK предупреждает.
- [x] Основной язык — русский (язык берётся из `vk_language`).
- [x] Подсказки новичкам — контекстные подсказки у шахт, ракет, ящиков, флагов. Отдельного обучения нет —
      если модератор попросит, это первое, что придётся добавить.
- [x] Реклама не показывается при старте и посреди боя — только после итогов и при выходе в меню.
- [x] Игровой валюты нет; личные данные не публикуются (берётся только имя как ник).
- [x] Уникальное название — проверить поиском по каталогу VK, что «Rocket Wars» не занято.
- [ ] Игра **включена** (Размещение → Состояние: Включено) — иначе заявку отклонят.
- [ ] Официальное сообщество — привязать в «Информация» (сменить можно раз в год после публикации).
- [ ] Кабинет выплат (cashout.vk.com) — без него показы рекламы не оплачиваются.
Проверка: 2–7 рабочих дней. Ответ модератора — в разделе «Модерация», чат с модератором.
