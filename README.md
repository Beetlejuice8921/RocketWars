# Rocket Wars

Многопользовательский воксельный шутер на Unity 6 (URP + Netcode for GameObjects): две команды на парящих островах
запускают ракеты по шахтам противника с пульта, отстреливаются, открывают ящики с лутом и воруют флаги.

## Запуск

- Unity **6000.3.19f1**, открыть папку проекта через Unity Hub.
- Сцена: `Assets/_Project/Scenes/Game.unity`.
- Игра по LAN: один игрок создаёт игру (хост), остальные подключаются из меню.

## Структура

- `Assets/_Project/Scripts` — весь код игры (бой, ракеты, острова, сеть, UI).
- `Assets/_Project/Resources` — материалы и шрифт, которые загружаются в рантайме.
- Модели, частицы и звуки генерируются кодом.
